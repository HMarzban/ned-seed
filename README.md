## Historical starter

This repository is the starter for the [Ned framework and CLI](https://github.com/HMarzban/ned). Read the framework overview for the source branch and related tools. The instructions preserve the original toolchain.

# Ned-seed
<a href="https://github.com/HMarzban/ned">Ned library</a> starter pack for <a href="https://github.com/HMarzban/ned-cli">Ned-Cli</a>

**Ned is:** a Super Light VanilaJS library with the ability of the big frameworks for creating a single-page web Application.
It gives your application Component and Module features for longer maintainable and scalable project support without worry about the complexity of your project in the feature.

**How to use ned-seed without cli** : 

 1. `git clone` ned-seed repository.
 2. `npm i`
 3. `npm start`
